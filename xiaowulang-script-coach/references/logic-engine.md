# 底层内容引擎

## 样本边界

- 来源为用户提供的 30 篇小五狼抖音视频逐字稿，包含知识讲解、人物史、方法清单、短句合集、互动选择题、Vlog 与商业植入等不同体裁。
- 逐字稿存在明显 ASR 错字、英文误识别、人物或术语错转写。只学习结构，不把转写内容当事实来源。
- 互动数据只能用于发现相关线索，不能证明某个结构单独导致高表现。

## 总体算法

`熟悉困境 → 二选一/矛盾问题 → 先给判断 → 借外部知识解释 → 翻译成生活例子 → 推出反直觉含义 → 给方法或判断 → 回扣开头`

真正可迁移的不是“今天我们来讲”或“好，下课”，而是四次翻译：

1. 把大知识翻译成观众正在经历的问题。
2. 把术语翻译成一句能复述的大白话。
3. 把理论翻译成可想象的人、动作与代价。
4. 把解释翻译成观众能使用的判断或方法。

## 六类主引擎

### 1. 机制解释型

适合：为什么、看不懂的现象、人性与商业机制。

结构：`反常现象 → 常见误判 → 模型/理论 → 逐层解释 → 现实推论 → 边界`。

质问重点：你反驳的到底是哪种旧解释？新机制比旧解释多解释了什么？

### 2. 决策工具箱型

适合：N 个原理、方法、避坑信号、行动建议。

结构：`结果承诺 → 统一母题 → 3–7 个不同工具 → 每点配场景 → 使用顺序或选择条件`。

质问重点：这些点是否真属于同一个问题？观众什么时候用哪一个？

### 3. 自我诊断型

适合：拖延、自控、认知盲区、老板和职场行为。

结构：`你以为自己是 A → 可观察症状 → 真正原因 B → 自测标准 → 改变动作`。

质问重点：症状是什么？如何排除另一个解释？不要给人贴无法验证的标签。

### 4. 人物/经典借力型

适合：人物一生、书籍、文章、历史与经典语句。

结构：`当代困境 → 人物/文本钩子 → 关键节点或概念 → 命运与思想互证 → 回到今天`。

质问重点：为什么此人能解释今天的问题？哪些史实必须核验？不要写成流水账。

### 5. 个人案例反推型

适合：项目复盘、创业、AI 落地、内容与获客。

结构：`具体失败/意外 → 当时的误判 → 关键证据 → 隐藏变量 → 新做法 → 适用边界`。

质问重点：现场发生了什么？哪个动作改变了结果？没有什么就不会成立？

### 6. 短句/选择互动型

适合：短时长情绪内容、身份表达、评论互动。

结构：`强设问或连续短句 → 意义反转 → 留白/选择`。

质问重点：用户是要表达立场还是传递知识？此类结构不能承载复杂因果论证。

## 常见段落微循环

每个主体段优先使用：

1. 报出概念或判断；
2. 用一句大白话定义；
3. 给一个观众熟悉的具体情境；
4. 追问“这说明什么”；
5. 推出一个反直觉含义；
6. 交付一个判断、动作或边界。

## 高互动相关线索

- 收藏占比较高的样本常含明确方法、决策框架、可复述清单或经典文本拆解。
- 分享占比较高的样本常含两难选择、身份对照、关系议题、日常健康疑问或能代替观众表达立场的句子。
- 短句合集和选择题可获得高转发，但不能据此推断长知识稿应被压成短句。
- 长稿能够成立的前提是开头先交代现实收益，并在中段持续用例子和小结重置注意力。

## 不能迁移的表层

- 固定的“OK 大家怎么想”“写在公屏上”“希望大家越过越好”“下课”。
- 未经核验的权威人名、年份、实验数字和绝对比例。
- 为喜剧效果使用的攻击性标签、粗口和过度概括。
- 把复杂心理或社会问题归结为单一机制。
