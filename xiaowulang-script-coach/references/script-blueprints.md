# 成稿与审稿蓝图

## 默认知识型逐字稿

1. **标题**：呈现最强冲突或明确收益，不堆满全部信息。
2. **开头 0–15 秒**：现实矛盾或二选一问题；让目标人群能对号入座。
3. **立论 15–35 秒**：先给核心判断，说明看完能获得什么。
4. **重定义**：把熟悉问题从表面解释改写为真正机制。
5. **知识锚点**：只引入能推动论证的模型、人物、文章或研究。
6. **主体 2–5 段**：每段使用“判断—解释—例子—推论—用途”微循环。
7. **个人落点**：加入创作者亲历、客户观察或明确立场。
8. **边界**：说明何时成立、何时不成立，避免绝对化。
9. **收束**：回扣开头，把复杂内容压成一句可复述判断或一个动作。
10. **互动**：只问与核心冲突直接相关的问题，不泛泛索要评论。

## 人物/经典型逐字稿

`当代困境 → 人物最戏剧性的矛盾 → 关键节点 → 思想/选择如何形成 → 对今天的解释 → 创作者判断 → 回扣`

不得把人物生平写成流水账。每个历史节点都必须服务当前命题。

## 案例反推型逐字稿

`结果异常 → 还原现场 → 当时误判 → 关键转折 → 隐藏变量 → 新规则 → 反例/边界 → 给观众的判断`

优先使用创作者在 `[你的真实经历领域]` 中亲自经历、能够说明细节且愿意公开的案例。安装后先替换此占位符，不得沿用他人的身份、客户或业务经历。

## 时长控制

- 60–90 秒：一个判断、一个例子、一个动作。
- 3–5 分钟：一个主机制、2–4 个主体段、至少一个真实例子。
- 6–10 分钟：允许多模型或人物脉络，但每 45–75 秒需要一次例子、小结、追问或转折。
- 超过 10 分钟：只有素材和证据足够时采用；先列章节，不靠重复注水。

## 口语化规则

- 使用短句和自然连接词，让句子能一口气读完。
- 术语出现后立刻用大白话解释。
- 允许少量幽默、自嘲和情绪，但不依赖粗口或攻击对象。
- 让创作者的判断来自经验与推理，不靠“我告诉你一个真相”的空架势。
- 避免连续三段使用同一种句式或同一种例子。

## 审稿清单

逐项回答是/否：

1. 开头指向具体人群和现实问题吗？
2. 核心结论能被反驳吗？若不能，它可能只是空话。
3. 知识锚点真的解释了问题吗？
4. 每个例子都支持相邻结论吗？
5. 是否从相关性偷跳到因果？
6. 用户未提供的经历是否被写进去了？
7. 是否有一个关键反例或边界？
8. 正文是否兑现标题和开头？
9. 结尾是否给出可复述的判断或动作？
10. 删除模仿口癖后，稿子是否仍然成立？
