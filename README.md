# 小五狼逻辑写作教练

一个面向知识型短视频的 Codex Skill。它不会直接套口癖，而是先通过“一轮一问”补齐真实经历、核心矛盾、证据、因果链和适用边界，再生成一篇可审计的口播逐字稿。

## 适合什么场景

- 把一个模糊想法、吐槽或观察发展成完整选题
- 通过连续质问补齐真实案例与论证缺口
- 诊断现有短视频稿件的逻辑、证据和边界
- 在明确假设与待补证据的前提下快速生成暂定稿

## 安装

将仓库中的 `xiaowulang-script-coach` 文件夹复制到你的 Codex Skills 目录：

```text
~/.codex/skills/
```

安装后的目录应为：

```text
~/.codex/skills/xiaowulang-script-coach/SKILL.md
```

## 使用前必须修改

打开 `xiaowulang-script-coach/SKILL.md`，找到“使用前配置”，把以下占位符替换成你自己的真实信息：

- `[创作者姓名或称呼]`
- `[你的真实经历与专业背景]`
- `[你的业务、产品或内容方向]`
- `[你的主要受众]`

再打开 `xiaowulang-script-coach/references/script-blueprints.md`，把案例反推型蓝图中的 `[你的真实经历领域]` 换成你能提供真实证据的领域。

不要填写虚构经历、客户数据或业务结果。若暂时没有案例，保留待补位标记，而不是让 AI 自动编造。

## 使用示例

```text
使用 $xiaowulang-script-coach，把“会用 AI 的人为什么还在天天加班”发展成一篇短视频稿。先质问我，不要直接成稿。
```

```text
使用 $xiaowulang-script-coach 诊断下面这篇口播稿，只指出最大的逻辑缺口，暂时不要重写。
```

## 方法边界

本 Skill 学习知识型短视频的内容工程与论证机制，不冒充任何创作者，也不机械复制个人口癖。仓库不包含原始逐字稿，仅包含抽象后的工作方法。
